# Progressive independence with controlled difficulty

ENNTOR draws on PRIMM (Predict, Run, Investigate, Modify, Make) and worked-example fading. These principles guide how we move from reading code to writing it. Their effectiveness depends on the learner, subject, and quality of the activities. [Curriculum and pedagogical references](Python_AI_Interview_Learning_Curriculum_v1.1.md#pedagogical-basis)

- **Modify** gives learners working code to understand and a specific change to make under clear instructions.
- **Build** asks learners to construct code from a partial structure. Reduce guidance in manageable steps as they take responsibility for more of the solution.
- **Make** asks learners to solve a fresh, related problem independently. Specify the required behavior and constraints. Leave implementation choices to the learner.

Write Make prompts as plausible assignments. State the desired result, interface, constraints, and examples. Describe domain rules in context and leave the sequence of operations and code structure open. When an activity explicitly assesses implementation mechanics, state the required technique and why it belongs to the learning objective.

Keep the main learning objective consistent as support fades. Change the context or structure enough to test transfer. Increase conceptual complexity separately and deliberately so reaching Make does not create an abrupt difficulty jump. Adjust the sequence and amount of scaffolding to the lesson, subject, learner evidence, and demonstrated competence. Establish prerequisites and teach the details the activity genuinely needs.

Reveal hints in order, starting with questions or observations. Record which hints the learner used and distinguish assisted success from independent mastery. After revealing a complete solution, require fresh independent evidence before awarding independent-skill status.

## Content review checklist

- Is the learning objective consistent across related stages?
- Does implementation guidance fade gradually?
- Does Make read like a real assignment with a precise contract and examples? Does it leave the method open, with any required technique justified by an explicit objective?
- Is Make genuinely different and appropriately related?
- Does each activity introduce only the intended new demands?
- Do hints become more helpful without prematurely revealing the solution?
- Are prerequisites taught or established?
- Does successful completion produce appropriate independent evidence?
